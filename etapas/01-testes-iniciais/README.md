# Etapa 01 — Introdução ao ESP32

**Código da etapa:** [serial_basico/serial_basico.ino](serial_basico/serial_basico.ino).

Exemplo curto para conhecer a placa, o Monitor Serial a 9600 baud e a leitura do sensor de luz no GPIO 34. Não move os motores e não precisa de Wi-Fi.

> Esta é uma reconstrução didática feita em 28/10/2026, não uma cópia comprovada do sketch inicial da dupla.

Para o teste de movimentação local exigido em 23/09, consulte a [Etapa 02 — Motores](../02-motores/README.md). Mantenha as rodas suspensas.
